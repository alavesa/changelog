# Figma Community Listing

## Tagline
Track how your designs evolve with visual changelogs.

## Description

Design Trail captures snapshots of your frames and generates visual changelogs — so you can see exactly what changed between design iterations.

**How it works:**
1. Select a frame and capture a snapshot
2. Make your design changes, capture another snapshot
3. Compare — see every change with before/after thumbnails

**What you get:**
- Visual side-by-side previews (thumbnails captured automatically)
- Every change listed: added, removed, and modified nodes
- Plain-English summaries — "Moved right by 10px" instead of raw diffs
- 30 properties tracked across layout, style, typography, and structure

**Built-in design review:**
- Approve, flag, or comment on each change
- Click any node to highlight it in Figma
- View how a single node evolved across snapshots
- Export review reports as Markdown, JSON, or CSV

**Designed for real workflows:**
- Auto-versioning (v1, v2, v3...)
- Annotations — explain why something changed
- Filter by change type or search by node name
- All data saved to the Figma file — shared with your team
- Up to 20 snapshots per file, 5,000 nodes per snapshot

No account needed. No external services. Everything stays in Figma.
